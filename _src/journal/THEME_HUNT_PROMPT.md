# Охота по темам

Журнал Orbiq: в выпуске 40+ историй, одна тема — одна история. Читатель: долларовый миллионер 50–70 лет, был в 40+ странах.

Прочитай перед работой: /home/claude/orbicgroup/journal/UNIQUENESS.md (особенно разделы 0, 3, 6, 10), FILTERS.md (41 фильтр), WRITE_PROMPT.md (формат статьи), AUDIENCE.md.

Для каждой своей темы найди 3 кандидата и расставь их по силе. Каждый кандидат:
- проходит тест повторения: читатель делает ровно то, что в заголовке (заказать, поехать, участвовать, купить, попасть);
- уровень эталона: ночь в храме Нинна-дзи (закрытое открыли для одной группы, знает узкий круг, пересказывается за ужином);
- заголовок до 7 слов, точный по смыслу, называет явление без инфинитива в начале («Ночь в императорском храме Киото», а «Купить…», «Найти…» запрещены), без жути и религии;
- реальный исполнитель с работающим сайтом, свежее упоминание 2025–2026;
- никаких фактов из памяти: только из выдачи WebSearch.

Формат: JSON-массив объектов по WRITE_PROMPT.md плюс поля "theme" (точно из списка тем UNIQUENESS.md раздел 10), "rank" (1–3), "repeat", "archetype", "img_idea" (что должно быть в кадре: человек в действии или вещь крупно) и "img_page" (страница героя или пресс-кит, где может быть кадр).

Инструменты: только WebSearch. WebFetch и curl для страниц не используй.
