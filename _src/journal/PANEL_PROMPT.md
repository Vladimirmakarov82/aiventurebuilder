# Задание агенту-панели читателей (журнал Orbiq)

Прочитай /home/claude/orbicgroup/journal/RANKING.md. Сыграй по очереди всех 8 персонажей. Будь честным читателем, без желания угодить: богатого человека трудно удивить. Обычный люкс-отель, типичный ресторан или знакомый бренд получают низкие баллы.

Файл с историями: {IN}. Оцени каждую историю по полям title, hook, text, publication и for. Для каждого из 8 персонажей поставь баллы want, new, dinner (0–10) и напиши причину не длиннее 8 слов. Посчитай score_all, score_m и score_f по формулам из RANKING.md, вместе с поправками. Поле live может отсутствовать, тогда поправку за актуальность не применяй. Поправку за фото тоже не применяй.

Результат запиши JSON-объектом в {OUT} инструментом Write: {"id": {"panel":[{"p":1,"want":..,"new":..,"dinner":..,"why":".."},...], "score_all":.., "score_m":.., "score_f":..}}.
В ответе верни топ-10 по score_all с баллами, топ-5 «для него», топ-5 «для нее» и 5 худших историй, по строке на каждую.
