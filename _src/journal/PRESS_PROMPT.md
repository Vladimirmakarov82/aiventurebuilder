# Задание: фото для журнала Orbiq из пресс-материалов

Файл: {IN}. Для каждой истории найди 1–2 сильных фото самого объекта: место, вещь, мастерская.

Порядок поиска:
1. Открой object_url (или найди официальный сайт). Найди раздел Press, Media, Press kit, Newsroom, Media center или Press room. Если там лежат фото для прессы, возьми прямую ссылку на файл изображения (jpg, png или webp) хорошего размера, от 1200 пикселей по ширине.
2. Если пресс-раздела нет, возьми фото с официального сайта объекта, но только если это сайт самого объекта и фото показывает именно его. Пометь такое фото usage="official_site".
3. Фото из статей журналов и стоковых агентств (Getty, Shutterstock и подобных) не бери никогда.
4. Проверь, что ссылка на файл открывается. Изображение должно быть фотографией: логотипы и схемы не подходят.

Запиши JSON-объект в {OUT} инструментом Write:
{"id": {"img_url": "...", "page_url": "страница, где нашел", "credit": "Фото: <название объекта>, пресс-материалы", "usage": "press_kit | official_site", "note": "..."}}
Если фото найти не удалось, запиши для этой истории null.
В ответе одна строка: сколько найдено press_kit, сколько official_site, сколько null.
